# ✅ TodoApp.pk

A beautiful **todo list app** — organize your day, saved automatically in your browser. No sign-up, no database!

## ✨ Features
- ➕ Add, ✏️ edit, ✅ complete & 🗑️ delete tasks
- 🔎 Filter: All / Active / Completed
- 💾 Auto-saved with localStorage (works offline)
- 📊 Tasks-left counter + clear completed
- Safe against HTML injection (escaped output)
